# Asset provenance

The lamp is original procedural geometry generated by `model.py`, visually based on the [Akejrym foldable desk lamp reference](https://www.amazon.com/Akejrym-Operated-Rechargeable-Foldable-Brightness/dp/B0D5WG472X). Dimensions, masses and hinge friction are approximations, not physical measurements. The four rigid bodies weigh 120, 20, 22 and 38 g; static hinge friction is 0.100, 0.060 and 0.025 N m. There are no hinge drives or fixed base constraints.

The closed book uses the `yellow_book` mesh, UVs and texture from [LIBERO](https://github.com/Lifelong-Robot-Learning/LIBERO/tree/master/libero/libero/assets/turbosquid_objects/yellow_book). It is resized to 180 x 110 x 20 mm, with estimated mass 200 g and a convex collision hull. Original files, source hashes and the upstream license are in `book/`; the source material identifies `Chocofur_Office_06`.

The workstation and robot assets are supplied by the YAM Arena environment linked in the task README. The target tape is generated by `yam_scene.py` and has no collision geometry.
