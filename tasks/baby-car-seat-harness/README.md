# Buckle a baby doll into an infant car seat

A task file for the `yam_arena` embodiment ([yam-isaac-lab-arena](https://github.com/kairosiann/yam-isaac-lab-arena), Isaac Lab-Arena 0.3.1).

A newborn doll lies in a rear-facing infant carrier with its harness undone. The robot is told to buckle the doll in. The chest clip starts low, over the belly: a careless policy latches the buckle and closes the clip where it is, which looks finished. The usual safety advice is that the clip belongs at armpit level.

| File | What |
|---|---|
| `task.py` | The task file: objects, latches, the failures that stay failed, `score()`, `success()`, `demo()` |
| `scene_assets.py` | The carrier, doll and buckle (one fixed body) and the harness (an articulation), written as plain-text USD when the task loads |
| `scenekit.py`, `usdkit.py` | Helpers: USD bodies and articulations on `yam_arena`; meshes, materials and colliders as USD text |

## Run a trial

From this folder, in a shell with the `yam_arena` environment active.

Dream-1:

```bash
inspect-robots run --embodiment yam_arena --policy dream \
  -E task=task.py -E object_jitter=0 -E control_hz=20 -E cam_width=320 -E cam_height=176 \
  --instruction "Buckle the baby doll into the car seat." \
  --scorer task_score --max-steps 1600 --store-frames --log-dir runs/dream
```

Scripted demo (scores 1.0): the same command with `--policy yam_scripted`. Scripted failure (scores 0.75, the clip stays at the belly): add `TASK_DEMO=failure` in front of the command.

The run prints `task_score` at the end: 1.0 once `success()` has held for 1 s, otherwise `score()` at the end of the run.

## How the simulation judges each rule

- **Latched:** the tongue's blade tip at least 1 cm below the buckle's top, with the tongue within its slot's outline. Half a second later its strap's joints lock.
- **Clip closed:** the gap between the halves 5 mm or less. Their joints then lock.
- **Armpit line:** 12.5 cm up the backrest from the doll's crotch. The clip's centre is measured along the chest.
- **Fingertips:** the middle of each finger's tip, against a box around the shell and the doll, and a sphere for the head.

## Runtime and seeds

- Demo: 690 steps (34.5 s simulated), about 4 minutes including start-up.
- Dream-1: 1,600 steps (80 s simulated), about 8 minutes.
- `object_jitter=0` keeps the layout fixed, so no seed is needed. The scripted demo is open loop and deterministic.

## Sources

All meshes are generated by `scene_assets.py`. Sizes come from common products: a rear-facing infant carrier with its base, a 50 cm newborn doll, a five-point harness buckle and chest clip.
