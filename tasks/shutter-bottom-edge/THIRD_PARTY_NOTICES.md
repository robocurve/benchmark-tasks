# Assets and runtime

All shutter, slide, button, witness and support geometry in shutter.usda was authored as primitive geometry for this task. No external CAD, photographs or textures are bundled. The two YAM arms, station and calibration come from the separately installed IsaacLab-Arena-YAM environment. The model uses the existing Inspect Robots Dream policy route. Source projects supply and license their runtime dependencies separately. The PR payload contains only this task and its fixture.

Runtime information: https://github.com/robocurve/inspect-robots
