The task models, wood texture, graduated tape and calculator label images are
original procedural assets generated by `model.py`, released under `LICENSE`.
Calculator labels use DejaVu Sans Bold glyphs; the font notice is included in
`FONT-LICENSE.txt`. The font itself is not bundled.

The calculator's appearance and key layout reference the
[CATIGA CD-8185](https://www.amazon.com/Desktop-Calculator-Sensitive-Standard-Function/dp/B083JR4BRZ).
The tape case's appearance references an
[Esydon tape measure](https://www.amazon.com/Esydon-Retractable-Self-Locking-Measurement-Handicraftsman/dp/B0BPT7C3KW/).
Product photographs, logos and downloaded product assets are not distributed.
The simulated tape deliberately uses automatic spring return without a lock.

Robot geometry, workstation assets and camera calibration are provided by the
external `yam-arena` dependency and are not vendored in this task.
