# Telescopic training rail

All dimensions in mm. Build one non-load-bearing practice rail. The server above or below it uses its own production rails. Set rack flange inside-face separation to 840, measured at both peg heights. Secure the rack base at four corners through the bench using four M8 bolts, washers, backing plates and locking nuts. Use factory base mounting holes and adjust bolt length to bench thickness. Remove casters. Measure the installed rack sheet thickness at the target holes (nominal 2.0).

With a 9.5 square rack hole, the straight hook shoulder must overlap the sheet edge by 1 mm at full return. Shim the shoulder axially until the locking face lies 0.0–0.4 beyond the outer sheet surface. Fit the guides against an actual coupon of the measured rack thickness. Set the hook stop to the fully extended position. Check a straight out-of-rack hook and a depressed hook with seated feeler both show orange. The visual mesh approximates the flag with two alternate coloured tabs.

Measure axial end insertion with a 0–50 N push/pull gauge, normal to the flange, five cycles per end. Adjust spring preload to an insertion peak of 10 ±1 N over the last 2.5 mm. Check that a 0.4 mm feeler is the largest that can pass when green. A 15 N axial pull for one second must leave the pegs seated and flag green. A false green, failed pull or out-of-band force invalidates fixture setup. The 150 N solver force cap is numerical, not a load rating. Record the five peaks and dimensions with the trial. The build has not been physically qualified. A green end in the wrong U still scores zero.

The rack depth settings are indexed in whole inches. Gauge the actual flange spacing. If it cannot be set to 840 mm directly, use the 34-inch setting and two rigid square-hole mounting strips on spacers, leaving exactly 840 mm between the inward-facing working surfaces. At exactly 863.6 mm host depth each strip plus spacer projects 11.8 mm. Attach outside the working holes and keep the outer flange clearance available to the latch.
