# Move a vial through a hot-cell wall with a pivoting tong

A vial stands inside a closed box with a clear window and roof. A steel tong passes through a gimbal in the box's wall, so the jaws move opposite to the handle: push the handle left and the jaws go right, push it down and they go up. The task is to lift the vial out of its rack, carry it across, and lower it into a holder only 1 cm wider than it is.

**Both arms are forced by layout and spring.** The jaws close only while a sprung lever is held pulled, and they open as soon as it is let go. The lever stands 34 cm from the handle at the start and never closer than about 15 cm at any pose the joints allow, against the gripper's 9.6 cm opening. So one arm holds the lever through the carry, and the other moves the handle. The arms cannot reach the vial: the wall stops them.

**Ability tested:** using a tool whose motion reverses through a pivot, seen from outside the wall.

## Requirements

`yam-isaac-lab-arena` with Isaac Lab-Arena 0.3.1 (`source <ARENA_DIR>/yam.env`). `mechkit.py` and `demokit.py` are in this folder. Importing `mechkit` hooks `yam_arena.scene` and `yam_arena.inspect_embodiment` without changing them on disk.

## Run a trial

```bash
inspect-robots run --embodiment yam_arena -E task=task.py -E object_jitter=0 -E control_hz=20 \
  -E cam_width=320 -E cam_height=176 --scorer task_score --max-steps 1400 \
  --instruction "Use the tong through the wall to move the vial from the blue rack into the grey holder, and leave it standing there with the jaws clear of it. Pull the red lever to close the jaws; they open when it is let go."
```

## Scripted demo

```bash
python demokit.py task.py OUT            # full score, with a video
python demokit.py task.py OUT --no-record --mode lifted,hold,near,slide,naive,miss20,reach
python3 check_score.py                   # the score lines on hand-built states, with no simulator
```

The demo reads the rod's joints and the vial's pose, as a camera could see them. It lifts the vial in a straight line, keeping its base over the holder's axis as the rod pitches. `TASK_DEMO` selects another mode: `none`, `left_only`, `right_only`, `lifted`, `hold`, `near`, `drop`, `outside`, `rack`, `slide`, `naive`, `wrong_way`, `miss10`, `miss20`, `reach`.

## Scoring

See `scoring` in `task.json`, and `judge` and `Trial` in `task.py`. A vial that tips past 45 degrees, falls off the bench or is dropped more than about 2 cm fails for the rest of the trial. Dropping it into the holder from above scores 0, even if it lands standing.

## Results

| Mode | What it does | Score |
|---|---|---|
| Dream-1 | Run at 320 x 176, 1,400 steps | 0.0 |
| `full` | The whole task | 1.0, at step 468 (23.4 s) |
| `lifted` | Stops holding the vial up | 0.25 |
| `hold` | Stops with it in the holder, jaws closed | 0.5 |
| `near` | Lets go in the holder, jaws left round it | 0.5 |
| `none`, `left_only`, `right_only` | Arms wait; lever only; handle only | 0 |
| `slide` | Drags it along the bench | 0 |
| `naive`, `wrong_way` | Moves the handle the way the jaws should go | 0 |
| `miss10`, `miss20` | Lowers it 1 or 2 cm off the holder's axis | 0 |
| `drop`, `outside`, `rack` | Lets go over the holder; stands it on the bench; puts it back | 0 |
| `reach` | An arm goes for the vial: the wall stops its fingertip 30 cm short | 0 |

The tolerance between 5 mm and 1 cm off axis has not been measured. At 1 cm the vial falls into the bore and scores 0 through the fall rule.

## Simplified

See `fidelity` in `task.json`. The vial tilts about 10 degrees when lifted, since it turns with the rod.

## Runtime and seeds

The demo takes 468 steps, about 90 s of wall time on one GPU at 640 x 360. There is no randomness: `object_jitter=0`, so no seed is needed.
