# Close a roll-top bread bin: draw its slatted tambour along the curved grooves, over the corner and down the front

A bamboo roll-top bread bin stands on the counter with a loaf inside, its roll top pushed open. The robot is told to
close the bread bin.

The roll top is a tambour: a row of slats whose end pins run in curved grooves in the side panels. It only moves
along its grooves, forward over the rounded front corner and down the front, and a pull across that path binds its
pins. The task tests drawing a constrained, articulated part along a curved path it cannot leave.

## Files

| File | What |
|---|---|
| `task.py` | The yam_arena task file: the bin and its grooved panels, the tambour, `success()` and `score()` |
| `partkit.py` | Rigid parts built from boxes and cylinders, with hinges, for yam_arena task files |
| `meshkit.py` | Meshes built in code (here the grooved side panels), with their colliders |
| `demo.py` | The scripted full-score demo and its negative variants |

## Run a trial

In the Isaac Lab-Arena environment from the simulation walkthrough, from this folder:

```bash
inspect-robots run --embodiment yam_arena --policy dream \
  -E task=task.py -E object_jitter=0 -E control_hz=20 -E cam_width=320 -E cam_height=176 \
  --instruction "Close the bread bin." \
  --scorer task_score --max-steps 1200 --store-frames --log-dir dream_out
```

## Scripted demo

```bash
python demo.py task.py demo_out                   # full score: writes demo_*_cam.mp4, setup.png, result.json
DEMO_VARIANT=short python demo.py task.py short   # handle drawn 45 mm along the grooves and left: 0.25
DEMO_VARIANT=down python demo.py task.py down     # handle pressed straight down, across the grooves: 0
```

The right arm pinches the handle ridge of the front slat and draws it along the grooves' path, forward along the top
and 60 degrees round the corner, turning its hand with the slat. It lets go and, with closed fingers tipped forward,
pushes on the back of the ridge the rest of the way round and down the front until the tambour is shut. The demo
reads only the layout (the grooves' centreline) and its own joints.

## Scoring

Evaluated every control step; the score at the end of the episode counts (`SCORE_OVER = "end"`).

- 1.0 (success, which must hold for 1 s): shut, the handle slat's pins within 4 mm of the grooves' lower ends, both
  grippers 30 mm or more from the handle slat, nothing moving.
- 0.75: shut, but a gripper is near or the tambour still moves.
- 0.5: the handle slat drawn past the curve onto the front run, not shut.
- 0.25: the handle slat was moved 30 mm along the grooves at some point.
- Otherwise 0.

## Runtime and seeds

About 1 minute per trial for the full 1,200 steps, plus Isaac Sim start-up. The layout is fixed (`object_jitter=0`);
there are no seeds to choose.

## Fidelity

Rigid bodies at true size. The tambour is thirteen rigid slats on a chain of hinges, each joint folding one way only (as the cloth backing of a real tambour allows); their pins slide in grooves cut in exact mesh side panels, with wood-on-wood friction. The bin is fixed. All geometry is generated by code in the package.

## Real-world build

- A bamboo roll-top bread bin about 393 x 295 x 185 mm with a slatted tambour (16 mm slats) in grooves, fixed to the
  counter with two strips of double-sided tape, and a loaf inside.

Check the result by eye: the handle slat rests on the bin's bottom rail and the roll top is closed.

All geometry is generated by code in the package; no third-party assets are used.
