CURRENT ASSETS — ORIGINAL ANALYTIC GEOMETRY

All current pen and cap geometry is authored by build_assets.py from analytic
cylinders, boxes and ring segments. No catalog mesh is included, downloaded,
referenced or required. The red and blue pens each contain only the four
original analytic cylinders: Barrel, Shoulder, Nib and End. The barrel is now
visible instead of being covered by a scan-derived mesh.

Regenerate with: python build_assets.py
Subset options: --pens-only or --caps-only
Current file hashes are recorded in provenance.json.

The cap bodies, visible liner and backing retain the prior geometric
engagement design. PHYSICAL_REPRODUCTION.md specifies PP bodies/shells,
polyester felt nibs and Smooth-On SORTA-Clear 40 silicone mechanically keyed
through four shell ports. Counterbored silicone heads capture each insert
without relying on an unspecified adhesive. Those internal keys and shell
weight-relief cavities are physical manufacturing details omitted from the
rigid simulation. The joint is an uncalibrated retention approximation.

Destination textures are task-authored text rendered with DejaVu Sans;
the font file is not bundled.

Historical note: earlier Git commits and retained trial recordings used a
catalog-derived barrel visual. The current analytic assets replace that mesh
rather than claiming newly verified rights to it. Prior recordings are
superseded evidence; they must not be relabeled as runs of the new visuals.
