# Asset sources and licences

The boot, runner, two guard cups, spring indicators, rest and gear bag are original, generated geometry under the MIT licence in this folder. No vendor media, meshes or marks are included. The Jackson Ultima links in the README document the physical mechanism.

The installed YAM/Arena adapter builds the standard bench and loads the robot at runtime. The YAM robot description and source meshes are distributed by [I2RT Robotics](https://github.com/i2rt-robotics/i2rt) under the MIT licence. The adapter documents the mesh source commit and accompanying notice in `yam_arena/assets/yam/SOURCE_COMMIT` and `yam_arena/assets/yam/LICENSE.i2rt`. This task includes no copies of the runtime or robot meshes.
