# Asset sources and licenses

## Robot model distributed with the task

Both arms reuse the same I2RT Robotics YAM v1 model. The revision pinned in `tea/assets/SOURCE_COMMIT` is `120c3c81400171174604e503943f8d1ebc891058`. Its URDF, nine STL files and original MIT notice in this package were compared byte for byte with the files at that upstream revision. [Source tree](https://github.com/i2rt-robotics/i2rt/tree/120c3c81400171174604e503943f8d1ebc891058/i2rt/robot_models/arm/yam/v1) · [Upstream MIT license](https://github.com/i2rt-robotics/i2rt/blob/120c3c81400171174604e503943f8d1ebc891058/LICENSE) · [Included copyright and permission notice](tea/assets/LICENSE.i2rt)

| Local files under `tea/assets/` | Location relative to upstream `i2rt/robot_models/arm/yam/v1/` | Use |
| --- | --- | --- |
| `yam.urdf` | `yam.urdf` | Link frames, joint axes and limits, visual transforms and link inertias |
| `base.stl`, `link1.stl`, `link2.stl`, `link3.stl`, `link4.stl`, `link5.stl` | `assets/` followed by the same filename | Base and articulated arm links |
| `gripper.stl`, `tip_left.stl`, `tip_right.stl` | `assets/` followed by the same filename | Gripper and fingers |

From the task root, verify the 11 local files against the SHA-256 digests computed from those upstream bytes.

```bash
(cd tea/assets && sha256sum -c UPSTREAM_SHA256SUMS)
```

## Scene, fixtures and media

| Item | Origin and terms |
| --- | --- |
| Mannequin, garments, mug, pitcher, table, stage, catchments, markers, collision pads and liquid marks | Task-authored primitive geometry, procedural colors and render overlays in `tea/`. The [fixture and scene asset MIT license](LICENSE.fixtures) covers task-authored procedural assets. Inspect the scene construction in `tea/scene.py`. The gradient sky texture is generated by MuJoCo from two RGB colors. |
| Fixture drawings, calibration materials and score sheets authored for the revision | Original technical drawings and materials distributed under the [fixture MIT license](LICENSE.fixtures). The license identifies its scope. |
| Screenshot and films | The task's MuJoCo cameras generate the pixels on each evaluated rollout. The original robot asset attribution above applies to the depicted arms. Inspect supplies the rollout/recording pipeline. Dream-1 is a separately hosted action policy. The task obtains actions through its installed provider and constructs scene appearance locally. |
| Text overlays on comparison media | The renderer uses the local installation of DejaVu Sans (Bitstream Vera license with public-domain DejaVu changes). Local verification resolved DejaVu Sans. When that typeface is unavailable, the exporter requests Pillow's installed default font. In the tested FreeType-enabled Pillow build this fallback is an Aileron Regular subset (CC0 1.0). Fonts are supplied by the renderer's environment. [DejaVu license](https://dejavu-fonts.github.io/License.html) · [Aileron author and license](https://dotcolon.net/fonts/aileron) · [Pillow font loader](https://pillow.readthedocs.io/en/stable/reference/ImageFont.html#PIL.ImageFont.load_default) |

## External software

The project installs MuJoCo 3.3.7 (Apache-2.0), Inspect Robots 1.0.0 (MIT), NumPy and SciPy (BSD-3-Clause for their core distributions) and Pillow (PIL/MIT-CMU). The numerical and imaging version ranges are in `pyproject.toml`. Their installed distributions carry the licenses for any included native libraries. FFmpeg with libx264 is a host executable used to encode H.264 files. Python wheels, the Dream provider, the encoder executable and rendering fonts come from the evaluation environment.
