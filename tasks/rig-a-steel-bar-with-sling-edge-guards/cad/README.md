# Printable parts

Generated by `python tools/build_cad.py` from the same layout as the simulated scene (`rdb_sling_guards/layout.py` and
`fixed_scene.py`; the scene file is built from the same numbers by `tools/build_assets.py`). Binary STL, millimetres.
Each file is a set of closed convex shells that touch; slicers union them.

No commercial magnetic sling protector is shorter than 6 in (the smallest DICA LiftGuard), more than the YAM gripper
opens (94 mm), so the edge guard is a printed part of the same kind: a rigid angle that sits on the bar's edge, held
there by magnets, with the web sling bearing on its rounded nose instead of on the sharp steel edge.

## Magnets

Each guard takes four K&J Magnetics D81-N52 neodymium discs (1/2 in x 1/16 in, 12.7 x 1.59 mm, grade N52). The
simulation takes 3.84 lb (17.1 N) as each disc's case-1 pull (a single magnet on a thick steel plate); K&J lists the N42
disc of the same size (D81) at 3.1 lb, and the N52 grade pulls about 1.2 times as hard (an estimate; TECHNICAL.md).
Glue one into each pocket with epoxy, its
face 0.5 mm below the flange's inside face so it cannot scratch the bar. Mind the polarity only for handling (the
guards stick to each other).

The simulation pulls each guard toward the bar with this pull falling off with the gap (17.1 N per disc at contact, a
quarter of that at 1 mm, nothing beyond 15 mm); the curve's shape is an estimate fitted to the maker's published
pull-versus-distance figures for thin discs (`layout.MAG_G0`).

## Assembly

1. Print four guards and two trays; glue the magnets into the guards.
2. Put a top-edge guard (as a tent, corner up) and a bottom-edge guard (on the block, the flange with the lobe
   standing on the outside) in each tray at the positions in `task.json`.
