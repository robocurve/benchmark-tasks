# Whittle a wedge-shaped end

The native demo scores **1.0** in 85 simulated seconds. Dream-1 scores **0.00** over its full 120-second allowance. Both frozen traces were replayed successfully; details are in `evidence/`.

Hold the blank and shave away from the supporting hand. The useful skill is a loaded, controlled cut along the grain; touching the blank with a knife does not earn credit.

## Run

Use the pinned Isaac/YAM environment in `ENVIRONMENT.json`, with this repository’s normal simulator installation, or run `bash bootstrap.sh` in a fresh Linux NVIDIA container. The bootstrap pins the simulator, robot adapter and model adapter; then use `/workspace/robocurve-sim/IsaacLab-Arena/.venv/bin/python` for the commands below. From this folder:

```bash
python run.py --mode demo --out /absolute/path/to/demo
python run.py --mode dream --out /absolute/path/to/dream
python rescore.py /absolute/path/to/demo
```

The demo uses 1,700 ordinary joint controls at 20 Hz, or 85 simulated seconds. The policy limit is 2,400 controls, or 120 seconds. On an NVIDIA L40S, the recorded demo took 20.7 minutes and the model run 36.4 minutes, including rendering; wall time varies with GPU load and model latency. No placement jitter or random seed is used. Dream uses the official adapter. Its 50 action requests required 49 expired-session recoveries (99 API attempts); all 2,400 actions ran in one physical episode, but model memory restarted. This is a limitation of this baseline, not proof that task difficulty alone caused the failure. The request/recovery log is retained. Credentials must never be added to the task folder.

## Physical setup and scoring

Use one uncut 12×12×180 mm basswood blank without knots or cracks, a sharp short carving knife, and a chip tray. The full dimensions, materials and starting layout are in `task.json` and `geometry.py`. The setup screenshot is a native simulator frame. The robot holds the wood rather than using a cutting guide. Replace the blank after each trial.

Score the finished wood with a ruler and callipers. Damage makes the score zero. Otherwise award 0.25 for a tip no thicker than 10 mm, 0.5 for no thicker than 6 mm, and 0.75 for a 40–50 mm continuous bevel ending in a 1–3 mm blunt tip. Award 1.0 only when that finished blank and the intact knife are resting in the tray and both hands have released them for 2 seconds. Other outcomes score 0.

## Approximation

The blank contains five coarse shaving volumes. They represent material removal; there are no pre-cuts in the real starting blank. A shaving separates only after the blade travels at least 40 mm along its cutting plane against 4 N resistance, accumulating more than 0.16 J. The force is an engineering estimate, not a measured basswood cutting curve. Equal and opposite native forces act on blade and wood. Cutting too deeply or breaking the blank invalidates the attempt. The robot cannot release material by proximity alone.

Fine grain, burrs and fibre fracture are omitted. Native contact, gravity, motor effort and finger friction move the knife, blank and chips. The controller reads object poses to choose robot joint commands; it never writes their poses. The physical test uses fresh timber and a real blade, without scored grooves, magnets or scripted detachment.

`trace_audit.py` replays the recorded scorer and checks that a severed shaving had sufficient loaded travel/work. Native footage still needs visual inspection; a numerical score alone is insufficient.
